    How to turn on real emails

    1. Create a free account at resend.com. Use the email address where you want to receive the test.
    2. In Resend, open API Keys, create a key with sending access, and copy it. It is only shown once.
    3. Paste it here, choose Live, and click Save settings.
    4. Type that same email address under Send a test email and click the button.

    With Resend's free test address (onboarding@resend.dev) you can only email the address you signed up with. To email other people, add a domain you own in Resend, verify it, and use an address on it as the From address. The free plan also has daily and monthly sending limits, so check Resend's pricing page.

    Your key is stored only on this computer, in the file settings.json. Don't share that file.

    SMS stays simulated: real text messages need a paid provider.
